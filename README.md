# Screen Time Tracker - Landing Page

A modern, responsive landing page for the Screen Time Tracker Android app. Built with HTML5, CSS3, and JavaScript, featuring a beautiful design and smooth animations.

## 🚀 Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean, professional design with smooth animations
- **Interactive Elements**: Engaging user interactions and micro-animations
- **Performance Optimized**: Fast loading times and smooth scrolling
- **SEO Friendly**: Optimized for search engines
- **Accessibility**: Built with accessibility best practices

## 📱 App Features Highlighted

- **Real-time Overlay**: Beautiful, customizable overlay showing screen time
- **Detailed Analytics**: Comprehensive analytics with daily, weekly, and monthly reports
- **Productivity Insights**: Intelligent insights about digital habits
- **Smart App Filtering**: Filter and categorize apps for better focus
- **Smart Notifications**: Intelligent notifications for healthy screen time
- **Export & Share**: Export data and share progress

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and modern structure
- **CSS3**: Advanced styling with Flexbox and Grid
- **JavaScript**: Interactive features and animations
- **Font Awesome**: Icons and visual elements
- **Google Fonts**: Inter font family for typography
- **Vercel**: Deployment and hosting

## 📁 Project Structure

```
├── index.html          # Main HTML file
├── styles.css          # CSS styles and animations
├── script.js           # JavaScript functionality
├── vercel.json         # Vercel configuration
├── package.json        # Project dependencies
└── README.md           # Project documentation
```

## 🚀 Deployment

This project is configured for deployment on Vercel:

1. **Automatic Deployment**: Connect your GitHub repository to Vercel
2. **Manual Deployment**: Use `vercel --prod` command
3. **Custom Domain**: Configure your custom domain in Vercel dashboard
